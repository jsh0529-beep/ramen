> 단순한 회사 소개가 아니라, **"왜 이 시대에도 신문이어야 하는가"** 를 묻는 영상.

※ 공식 CI(로고)는 쓰지 않고 글자로만 제호를 조판한 **시안(콘셉트) 영상**입니다. 실제 송출 전에는 공식 로고와 사실관계를 매일신문 측과 확인해 주세요.

## 사실 근거 (검색 확인)

- **창간**: 1946년 3월 1일 대구 대안동에서 「남선경제신문」으로 창간, 1950년 「대구매일신문」으로 개칭, 2026년 창간 80주년. — [대구역사문화대전 『매일신문』](https://www.grandculture.net/daegu/toc/GC40005838), [매일신문 「지역민과 함께한 정론의 80년」](https://www.imaeil.com/page/view/2026070610063625444)
- **1955년 '백주의 테러'**: 9월 13일 주필 최석채의 사설 「학도를 도구로 이용하지 말라」(관제 데모 학생 동원 비판), 이튿날(9월 14일) 괴한 20여 명이 신문사를 습격해 제작(문선) 시설 파괴. — [대구역사문화대전 「대구매일신문 피습사건」](https://daegu.grandculture.net/daegu/toc/GC40001264), [매일신문 「1955년 '백주의 테러' 70년」](https://www.imaeil.com/page/view/2025090311454346972)
- **2·28 민주운동(1960)**: 대구 고교생들이 행진하며 매일신문사 앞을 지나고 도청으로 향함. — [Daegu Democracy Movement (Wikipedia)](https://en.wikipedia.org/wiki/Daegu_Democracy_Movement)
- **종이 읽기와 이해도**: Delgado 외(2018) 메타분석, 54편 연구·171,055명, 화면보다 종이에서 이해도가 높음(특히 설명·정보 글). — [Educational Research Review / ResearchGate](https://www.researchgate.net/publication/330854760_Don't_throw_away_your_printed_books_A_meta-analysis_on_the_effects_of_reading_media_on_reading_comprehension)
- **지역신문 폐간과 공공 비용**: Gao, Lee & Murphy(2020), 미국 지역신문 폐간 후 지방채 발행 비용 상승. — [Rebuild Local News](https://www.rebuildlocalnews.org/local-news-shortage-leads-to-1-1-billion-in-extra-borrowing-costs-for-local-governments-and-taxpayers/)
- 참고: 한국 뉴스 신뢰도 31%(48개국 중 37위), 포털 경유 이용 63% vs 언론사 직접 방문 6% — [디지털 뉴스 리포트 2025 한국](https://www.kpf.or.kr/front/research/selfDetail.do?seq=600080)

## 다시 만들기

```bash
./fetch_fonts.sh                 # Noto Serif KR / Noto Sans KR 내려받기 (fonts/, git 제외)
python3 audio.py                 # soundtrack.wav 합성 (numpy)
node render.mjs frames/v.mp4 30  # scene.html 을 프레임 단위 캡처 → H.264 (Playwright + ffmpeg)
ffmpeg -i frames/v.mp4 -i soundtrack.wav -c:v copy -c:a aac -b:a 192k -shortest maeil_promo.mp4
```

- `scene.html` — 모든 장면을 `render(t)` 하나로 그리는 결정적 애니메이션. 브라우저에서 열고 콘솔에서 `render(70.3)` 처럼 특정 시점을 확인할 수 있습니다.
- `node render.mjs --stills 3,30,70` — 지정한 시점의 스틸 컷을 `frames/` 에 저장.
- 자막 문구와 타이밍은 `scene.html` 의 `data-in` / `data-out`(초) 값만 고치면 됩니다.
